# Playable vertical slice — Year 1, Semester 1 (Phase 2 target)

One complete semester, start to results, on a phone.

**Loop:** plan week → resolve actions → story event → choices → feedback → next week → … → exams → results slip.

| Piece | Scope for the slice |
|---|---|
| Time | 12 teaching weeks + exam week (configurable). 10 action slots a week: weekdays and weekend. |
| Activities | Attend lectures, private study, library, assignment, part-time shift, rest, socialise, call home, club taster. Each is data: slot cost, energy/money cost, effects, location. |
| Academics | Per course: attendance, two assignments, one quiz, a mid-semester test, final exam. Score = weighted preparation and attendance, scaled by course difficulty, plus bounded seeded noise (±5) so steady work cannot be overturned by luck. |
| Story | 20 events across hostel, academics, money, friendship and family, including "The Surprise Quiz". Eligibility by week, location, flags and stats; cooldowns; follow-ups. |
| NPCs | Roommate, two course mates, one lecturer, one family contact — with memory flags written by event choices. |
| Money | Weekly food, transport and data costs; part-time income; one emergency expense event. |
| Map | Five locations first: hostel, lecture halls, library, cafeteria, student centre. |
| End of term | Results slip with per-course grades, semester GPA, probation/scholarship check, and a summary of the choices that mattered. |

**Done when** a new player can go from registration to a results slip without leaving the app, close the browser mid-week and resume, and the Playwright flow covering that passes at 360 px.
